<h1>Finance Tracker</h1>

<p>A simple, intuitive way to understand your spending and take control of your finances.</p>

<h2>Features</h2>

<ul>
<li><strong>Dashboard Overview:</strong> View chart analysis of the dashboard</li>
<li><strong>Transaction View:</strong> View all transaction expenses</li>
<li><strong>Transaction Add: </strong> Add new transactions to the application</li>
</ul>

<h2>Getting started</h2>

<h3>Installation</h3>

<ol>
  <li>
    Clone the repository:
    <pre><code>git clone https://github.com/deze-alu/alu-responsive-ui-summative.git</code></pre>
  </li>
  <li>
    Navigate to the project directory:
    <pre><code>cd alu-responsive-ui-summative</code></pre>
  </li>
  <li>Open the project using a local development server, such as the VS Code Live Server extension.</li>
  <li>Open the local URL provided by your server in a browser.</li>
</ol>

<p><strong>Note:</strong> Use a local server instead of opening <code>index.html</code> directly. Native JavaScript modules and HTML templates loaded with <code>fetch()</code> require an HTTP server.</p>
